📌 Overview

HemoNova is a modern cross-platform Blood Bank Management & Emergency Blood Response System built to reduce the time between a critical blood requirement and an actual life-saving donation.

Developed using Flutter and powered by Firebase, HemoNova delivers a real-time healthcare ecosystem that enables:

Live blood availability tracking
Emergency donor coordination
Smart donor management
Real-time communication
Secure authentication
Scalable cloud infrastructure

Unlike traditional blood-donation directories, HemoNova focuses on real-time emergency response, intelligent donor connectivity, and institutional coordination.
